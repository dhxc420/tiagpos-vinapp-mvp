tiagPOS / Vinapp-MVP

Proyecto local MVP inspirado en Vinapp. Contiene frontend estático (frontend/) y backend Express con DB en archivo (backend/db.json).

Cómo ejecutar localmente

1. Abrir terminal en backend/
2. npm install
3. npm start
4. Abrir http://localhost:4000 en el navegador

Notas:
- No subir backend/db.json real al repositorio (contiene datos de ejemplo y hashes). Se incluyó db.sample.json como semilla.
- Para producción se recomienda un host para Node (Render, Railway) y migrar la persistencia a una base de datos.
